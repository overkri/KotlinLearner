# Квиз 11 — Ktor для продакшена

## 1. Чем liveness отличается от readiness?
<details><summary>Ответ</summary>Liveness отвечает «процесс жив, можно не перезапускать»; readiness — «можно отправлять трафик». Liveness не должен проверять внешние зависимости, иначе временный сбой БД вызовет перезапуск подов.</details>

## 2. Почему проверки только подписи JWT недостаточно?
<details><summary>Ответ</summary>Токен может быть выпущен другим сервисом с тем же ключом или для другой аудитории. Нужно проверять `issuer`, `audience`, `exp`, а при необходимости — роли/scope.</details>

## 3. Что делает `validate { credential -> ... }` в Ktor JWT?
<details><summary>Ответ</summary>Решает, принять ли уже проверенный токен: вернуть `JWTPrincipal` (или другой principal) для авторизации либо `null`, чтобы клиент получил 401. Здесь проверяют subject, роли и бизнес-условия.</details>

## 4. Зачем `X-Request-Id`?
<details><summary>Ответ</summary>Связывает логи, метрики и ошибки одного запроса между сервисами. Клиент может передать свой id; сервер генерирует, если его нет, и возвращает в ответе.</details>

## 5. Почему метрика с label `accountId` опасна?
<details><summary>Ответ</summary>Высокая кардинальность: миллионы значений создают миллионы time series, Prometheus падает по памяти. Используйте ограниченные labels: route, status, error_code.</details>

## 6. Что должен сделать сервис при graceful shutdown?
<details><summary>Ответ</summary>Перевести readiness в false, дать балансировщику убрать под из ротации, дождаться in-flight запросов, остановить consumer'ов/Kafka, закрыть пулы, затем завершиться.</details>

## 7. Почему `/metrics` нельзя отдавать всем?
<details><summary>Ответ</summary>Метрики раскрывают внутреннюю топологию, нагрузку и имена сервисов. Их закрывают network policy, basic auth или отдельным портом.</details>

## 8. Что попадёт в лог при `log.info("token=$token")`?
<details><summary>Ответ</summary>Полный JWT (или его часть) — секрет, который можно использовать для доступа. Токены и пароли не логируют; маскируют или логируют только `jti`/subject.</details>
